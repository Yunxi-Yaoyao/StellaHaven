# 自动目录页与文章页

## 行为

- 页面类型由同工作区真实 parent_id 关系自动推导，无须修改类型字段：有直属子页面为目录页，否则为文章页。标题显示 folder/note 图标；正文始终可编辑。
- 标题下方展示自动目录，默认只列直属页面；独立展开按钮展开下一层，名称按文档ID导航。排序沿用侧栏数字/拉丁/中文标题顺序。
- 底部子页面标签移除；反向引用改为默认收起的“被 N 篇文章引用”，展开为逐行列表。
- 手机 <=768px 且有正文时目录默认收起；空正文目录默认展开。手动折叠选择按账号/工作区/页面保存，覆盖响应式默认值。
- 元信息来自allDocs完整工作区清单，搜索匹配列表docs与目录数据分开，防筛选后目录丢子项。完整刷新替换清单以反映改名/移动/删除；登出清空。
- 目录并非Markdown内容，不触发正文dirty/草稿/保存，不删除已有手写目录、双链或其他正文。空文件夹没有下挂时表现为普通文章。
- 目录“新建子页面”弹窗可选空白/文章模板（摘要、结论、原理、操作、验证、关联、参考、待办）；创建parent_id固定当前页。当前正文有修改时先保存；失败不创建。
- 长目录限高滚动，长标题省略，异常循环/重复ID不导致无限展开。
