# 16 - Stella 前端落地路线

> 2026-08-09 · 老婆拍板版。定位：**Stella 不是笔记应用，是个人面板**——笔记只是第一个模块。

## 一、需求分析

### 布局定稿（老婆亲口描述 + 确认）

```
┌────────────────┬─────────────────────────────────┐
│   [头像]        │                                 │
│   云曦          │                                 │
│   「签名」      │                                 │
│  ────────────  │      右侧：当前模块内容区          │
│  🏠 个人主页    │      （点哪栏换哪页，单页切换，    │
│  📝 笔记       │       不开多标签页）               │
│  🖼 图库       │                                 │
│  📊 服务器状态  │                                 │
│  ────────────  │                                 │
│  [扩展小模块位]  │   （时钟/状态之类，装饰阶段再加）  │
└────────────────┴─────────────────────────────────┘
```

侧边栏 = **App Shell**：永远挂载，三段式（个人名片区 → 导航区 → 扩展区）。
右侧 = `router-view`，单页切换，不做多开标签页（明确否决，后续也不升）。

### 模块清单（初版）

| 模块 | 后端状态 | 前端里程碑 |
|---|---|---|
| 个人主页 | 无（纯前端展示即可起步） | M1 占位 |
| 笔记 | ✅ 全部就绪（CRUD/草稿/搜索/回收站/乐观锁） | M2 |
| 服务器状态面板 | ❌ 需在 Stella 后端加 /status 模块 | M3 |
| 图库 | ❌ 等附件后端（文件系统+DB 元信息） | M4 |

## 二、技术选型（已拍板）

| 项 | 选择 | 理由 & 备选 |
|---|---|---|
| 框架 | Vue 3（组合式 API + `<script setup>`） | 求职目标栈 |
| 构建 | Vite | 标配 |
| 语言 | **TypeScript** | 招聘市场 Vue 岗默认 TS；摩擦换面试分 |
| 路由 | Vue Router | 每模块一条路由 + `import()` 懒加载 |
| 状态 | Pinia | 每模块一个 store |
| UI | **手写组件 + CSS 变量 design token**（老婆定的 C） | Element Plus/Naive UI 备选弃用——脸要是自己的；「自建 design token 体系」本身是面试加分项 |
| HTTP | fetch 封装一层（或 axios） | 先 fetch 手写封装，学习价值高 |

## 三、Design Token 初案（高级二次元 · 暗夜系）

开工第一步就是定义这套变量，全站只引用变量不写死色值：

```css
:root {
  /* 底色：深夜蓝黑三层 */
  --bg-base: #0d0f14;      /* 最底 */
  --bg-panel: #14171f;     /* 侧边栏/卡片 */
  --bg-raised: #1b1f2a;    /* 悬浮/输入框 */
  /* 主色：月白银 */
  --accent: #c9d4e8;
  --accent-dim: #8a94ab;
  /* 点缀：一点樱粉（克制用） */
  --pink: #e8a0bf;
  /* 文字 */
  --text-hi: #e8ecf4;
  --text-lo: #9aa3b5;
  /* 圆角/阴影/毛玻璃 */
  --radius: 12px;
  --blur: blur(12px);
}
```

风格关键词：**暗夜底 + 银白主色 + 一点粉点缀、圆角卡片、侧边栏毛玻璃、微动效（hover 浮起/过渡 200ms）**。
审美验收人是老婆，token 值开工后可调。

## 四、里程碑

### M0 脚手架（0.5 天）
- Vite + Vue3 + TS + Router + Pinia + ESLint
- 目录：`src/shell/`（外壳）、`src/modules/{home,notes,status,gallery}/`、`src/stores/`、`src/api/`
- 验收：`npm run dev` 起空壳，路由能切四个空白页

### M1 App Shell（1~1.5 天）⭐ 脸在这
- 侧边栏三段式：名片区（头像/名字/签名）→ 导航（图标+文字，当前项高亮）→ 扩展区占位
- 毛玻璃 + 暗夜 token 落地；窄屏折叠成图标栏（苏菲竖屏/手机考虑）
- 个人主页 placeholder（一张卡片即可）
- 验收：老婆肉眼验收——侧边栏质感、切换过渡、高亮态。**这关老婆说了算**

### M2 笔记模块（2~3 天）⭐ 肉在这
- 左：文档列表（搜索框置顶，接 `/documents/search`）
- 右：编辑器 + 预览
  - 编辑器选型到 M2 再定：A. textarea+marked（简单）B. CodeMirror 6（专业）C. milkdown（所见即所得）。娅娅倾向 A 起步
- 保存：Ctrl+S / 按钮 → PUT（乐观锁；409 → 静默重拉 DB）
- 草稿：输入 debounce 2.5s → WS `type:"draft"`；打开文档看 `has_draft` → 提示条「[设备] [时间] 有份未保存草稿 [查看][采用][忽略]」
- 回收站：列表/还原/彻底删
- 验收：场景一二三全演一遍（苏菲写一半→台式机看到草稿→采用；断网重连重拉；搜中文子串）

### M3 服务器状态面板（1 天）
- Stella 后端加 `/status` 模块：psutil（CPU/内存/磁盘/负载）+ docker 容器状态， Nyarch 本机数据
- 前端卡片网格 + 定时轮询（10s）
- 验收：面板数据和 `docker ps` / `htop` 对得上

### M4 图库（后置）
- 等附件后端（文件系统 + DB 元信息），前端瀑布流
