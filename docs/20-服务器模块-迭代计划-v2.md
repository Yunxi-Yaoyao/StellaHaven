# 服务器模块迭代计划 v2（2026-08-19 定稿）

> 来源：2026-08-19 凌晨 云曦 & 娅娅 逐条评审讨论。本文档是任务列表 + 已拍板决策 + 暂缓清单。
> 上一版方案见 `18-服务器监控模块-方案设计.md`、`19-防火墙与IP模块-方案设计.md`。

## 已拍板决策（讨论结论）

1. **详情页恢复独立路由** `/status/:id`——Vue Router 前端路由不刷新页面，左侧外壳不闪，体验与内部视图一致；解决刷新丢现场 / 浏览器后退 / 收藏分享。
2. **三重标题**：删模块左栏头部「服务器」，页内 h2 保留。
3. **工具导航**：点「工具」展开 + 跳默认子项（打流）；工具视图下父项淡色高亮；展开交互抄笔记模块树。
4. **OS 采集**：agent 读 `/etc/os-release` PRETTY_NAME（Windows 读 Caption），nodes 表加 `os_name`，心跳上报；卡片 chip / 详情头部显示 OS 名；存量 Stella 节点 platform 修回 linux。
5. **服务监控管理入口只在总览**（弹窗含节点筛选，配置项全：名称/类型/目标/间隔/超时/探测节点）；详情页服务监控 tab 只读 = 列表 + 状态 + 延迟曲线（1h/6h/24h/7d/30d + 实时模式）。
6. **详情页快捷操作走跳转**：头部「操作」下拉（打流/MTR/命令/此节点记录）→ `/status?view=tools&tool=x&node=id`，工具页读 query 预填。不做浮窗。
7. **记录页 A+B 都做**：工具页历史增强（时间戳/节点名/输出默认折叠/最近若干条）+ 独立「记录」页（三类任务统一时间线、按节点/类型过滤、点开展详情）。同一份数据，不另存。保留策略：每类最近 100 条自动清理。
8. **两张图（流量/系统指标）共享一组时间控件**：预设 1h 6h 24h 7d 30d 90d 180d 本月 上月 自定义；自定义从原生 datetime-local 换成深色主题弹层。
9. **实时模式**：窗长 5m/15m/30m/1h/2h/自选；每 3s 增量拉取（`start=最后一点`），echarts 尾部追加不重绘；范围模式加载后不自动重刷。头部状态/存储/监控保持 5s 轮询。后端零改动（接口已支持 start/end）。
10. **打流服务端约束**：公网节点打 badge；服务端下拉只列公网在线节点（一台公网自动选中）；客户端下拉排除已选服务端；两端只列在线节点。
11. **打流管道补洞**：①前端轮询改增量 `?after=N`；②任务看门狗（running 超 duration+60s 标 failed「agent 失联」）；③结果摘要落列（带宽/丢包/抖动独立列）；④前端任务阶段提示（等待服务端→等待客户端→测速中→回传中）。
12. **总览页三区**：服务器卡（可点击、OS、CPU/内存迷你条）/ 流量速览（选一台看实时）/ 服务监控（图表模式 ⇄ 简易模式切换；添加按钮回标题旁）。
13. **防火墙分期**：一期结构化展示（ufw status numbered + iptables-save 五表 filter/nat/mangle/raw/security 解析成表格，raw/security 折叠）；二期 ufw 进组件代装框架；三期规则增删（高危，参考改 IP 的回退机制）。PBR 先结构化展示。
14. **Docker**：检测（心跳组件探测）+ 容器列表面板 + 启停重启（走命令通道固定模板）+ 代装，一批做完。
15. **网卡列表**：默认隐藏 lo/docker/虚拟，面板头「全部 N 张」开关。
16. **speedtest 补完**（现状：subprocess.run 阻塞 90s 全程无进度、不能选测速服务器）：阶段式进度提示（选服务器→ping→下载→上传）+ speedtest-go `--list`/`-s` 服务器选择 + 结果卡片完善。
17. **打流历史「数据异常」脏数据**：由看门狗 + 摘要落列根治；存量脏记录随清理策略淘汰。
