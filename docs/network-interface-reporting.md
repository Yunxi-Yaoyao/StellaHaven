# 网卡流量：采集与显示分离

agent 0.6.9开始对当前存在的所有网卡读取计数、计算增量并上报，包括物理网卡、WireGuard、TUN、loopback、Docker网桥/veth。`monitored_ifaces`字段保留兼容，但仅决定默认图表/详情显示，不再过滤agent流量上报。

- 首次启动仅建立基线，下一采样周期开始报增量。
- 新出现/消失后重新出现的网卡先建立自身基线，不把累计字节伪装成一个周期流量。
- 计数器重置时跳过负增量，下一周期从新基线继续。
- 选择/取消显示不停止其他网卡的采集，也不删除历史。
- 先前没有上报的时间段不能重建，不补造历史数据。
- 每接口分别存储，不将WG/TUN/物理接口直接相加当作唯一公网流量，避免同一数据多层重复计数。

全量接口会增加上报量和历史存储（尤其是大量动态veth的主机）；这是全网卡保留历史的直接成本，不静默删减接口或改变既有保留策略。
