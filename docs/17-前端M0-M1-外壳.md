## 二、关键概念拆解

### design token 是什么

全站颜色/圆角/动效只写在 `:root` 的 CSS 变量里（`--bg-base`、`--accent`……），
组件里只许 `var(--xxx)` 引用。换肤 = 改一处，全站生效。
面试话术：「设计决策集中成 token 层，组件只消费 token」。

### App Shell 模式

`App.vue` = 永远挂载的外壳（侧边栏），`router-view` = 切换的内容区。
- 加新模块 = `modules/` 加个目录 + `router/index.ts` 加一条路由 + SideBar 加一项
- 路由用 `() => import(...)` 懒加载 → 首屏只下载外壳，点进哪个模块才加载哪个
  （build 产物里能看到每个页面独立的 chunk 文件，这就是代码分割）

### 页面切换过渡

```vue
<RouterView v-slot="{ Component }">
  <Transition name="fade" mode="out-in">
    <component :is="Component" />
  </Transition>
</RouterView>
```
`v-slot` 拿到当前路由对应的组件，包进 Transition，切页时有 200ms 淡入。

### 当前导航高亮

`:class="{ active: $route.path === item.to }"` —— `$route` 是路由器给的当前路径，
命中就加 active 样式（左侧银条 + 提亮）。

### 响应式折叠

`@media (max-width: 768px)` 时侧边栏收成 64px 纯图标栏——
苏菲竖屏/手机场景。从 M1 就内建，不后补。

## 四、M2 笔记模块（同日追加）

### 结构


### 数据流（对应后端设计）

```
打字 → debounce 2.5s（且 dirty 才发）→ WS draft → 草稿槽
Ctrl+S/按钮 → PUT（带 updated_at 乐观锁）→ 成功清草稿槽 / 409 静默重拉
打开文档 → has_draft → 提示条 [查看][采用并保存][忽略]
doc_saved 广播 → 本地不脏：静默重拉；本地脏：提示不覆盖
```

### 两个实盘 bug（都有教学价值）

**bug 1：草稿复活竞态**
采用草稿 → save 清槽 → 但 2.5s 前挂起的 debounce 定时器又触发，把内容写回槽里——草稿「复活」。
修：草稿同步加 `dirty` 守卫（只在有未保存修改时才发）+ save 时 clearTimeout。
教训：**debounce 回调触发时，世界可能已经变了——回调里要重新检查前提条件。**

**bug 2：`db.close` 漏了 `()`（本次 MVP 级 bug）**
`database.py` 的 get_db 里 `finally: db.close`——属性引用不是调用，**连接从不释放**。
浏览器实测时每个请求漏一个连接，QueuePool(5+10) 榨干 → API 500。
**为什么 47 个测试没抓到**：测试用 dependency_overrides 共享 session，真实的 get_db/close
路径从未被执行。教训：**override 机制测试的是业务逻辑，测不到基础设施层。**
排查路径：console API 500 → uvicorn 日志 QueuePool TimeoutError →
pg_stat_activity 看到一片 idle in transaction → 每个请求都漏 → 回到 get_db 源码。

附带加固：`pool_pre_ping=True`（防陈旧连接）；save_draft 幽灵路径显式 rollback。
