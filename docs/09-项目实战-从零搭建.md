## 三个核心概念

### engine — 发动机
```python
from sqlalchemy import create_engine
engine = create_engine(settings.database_url)
```
就是你跟数据库之间的"管道"。给它地址，它负责连接、执行 SQL、返回结果。

### session — 一次会话
```python
from sqlalchemy.orm import sessionmaker
SessionLocal = sessionmaker(bind=engine, autoflush=False)
```
每次 HTTP 请求都是一次"对话"。工厂吐一个 session，干完活关掉。`autoflush=False` = 不自动刷库，让你控制时机。

### Base — 模型的祖宗
```python
from sqlalchemy.orm import DeclarativeBase
class Base(DeclarativeBase):
    pass
```
所有表模型（User、Document…）都继承它。Alembic 靠它知道有哪些表要迁移。

### get_db — FastAPI 依赖注入
```python
def get_db():
    db = SessionLocal()
    try:
        yield db      # 把 db 借出去用
    finally:
        db.close()    # 用完了回来收拾
```
路由里写 `db = Depends(get_db)` 就自动注入，请求结束自动关。不用手动 with。

## 常用命令

```bash
# 进虚拟环境
source .venv/bin/activate

# 装依赖
uv add fastapi uvicorn sqlalchemy psycopg2-binary alembic pydantic-settings

# 启动开发服务器
uv run uvicorn main:app --reload --port 12031

# 生成迁移
alembic revision --autogenerate -m "描述"

# 应用迁移
alembic upgrade head

# 回滚
alembic downgrade -1

# git 三连
git add . && git commit -m "xxx" && git push
```

## 踩坑记录

### 1. Docker PostgreSQL 用户名不是 postgres
1Panel 安装的 PostgreSQL 容器默认用户是 `yaoyao`，不是 `postgres`。用 `docker inspect` 看环境变量确认。

### 2. 密码里的 `@` 是 URL 保留字
`St@106954021` 拼进连接字符串会被当成 `user:pass@host` 的分隔符，导致连接地址错误。

**解决**：用 `urllib.parse.quote_plus` 编码：
```python
from urllib.parse import quote_plus
f"postgresql://{user}:{quote_plus(password)}@host:port/db"
# 输出：postgresql://stalla:St%40106954021@localhost:5432/stella
```

### 3. Alembic `engine_from_config` key 是 `url` 不是 `sqlalchemy.url`
```python
# env.py 里
connectable = engine_from_config(
    {"url": settings.database_url},   # ✅ key 是 "url"
    prefix="",                        # prefix="" = 不剥前缀
    poolclass=pool.NullPool,
)
```

### 4. Alembic 不要写死地址在 ini
让 `alembic/env.py` 从 `app.config.settings` 读——一个真相来源，改一处全生效。`alembic.ini` 里那行 `sqlalchemy.url` 不需要改。
