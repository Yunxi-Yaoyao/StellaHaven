# 服务器总览：世界地图与 WireGuard 链路

## 行为

总览标题后显示横向地图，原服务器卡片、流量和监控区保持原顺序。地图使用本地 Natural Earth 数据和现有 ECharts，不依赖在线地图瓦片。

- 公网节点仅接受已验证的 NAT 出口城市坐标，或管理员显式设置的位置。获取失败、缺少坐标、只有节点名/region/WG IP 时均未知；内网节点需人工位置。
- 人工位置优先且保存在独立配置键，不被 agent 上报覆盖；清除后恢复自动来源或未知。坐标为经纬度，不表示精确机房/住宅地址；出口位置未必等于设备物理位置。
- WireGuard 根据真实接口公钥指纹匹配 peer，公钥先做 SHA256；不读取私钥或预共享密钥，不用 `wg dump/showconf`。
- 每个实际接口对只形成一条链路，重复/冲突公钥不猜对应节点。同城/同坐标节点聚合；端点未知的链路保留列表、不发明坐标。多个隧道分别保留。
- 握手近180秒为“近期握手”，旧握手为“过期”，0为“从未”，节点离线/采集过期/时间异常为“未知”；这些不是Ping时延或业务可达性的证明。
- 地图缩放/拖动在刷新后保留，折叠记忆；手机上下布局，只有位置编辑是管理员操作。未知位置与未识别对端均可查。

## 数据路径

agent `collect_map_snapshot()` → `AgentReport.map_snapshot` → AppConfig `node_map_snapshot:<id>`；人工覆盖键 `node_map_manual:<id>`。

- `GET /nodes/map-topology`：遵循现有节点列表登录权限，只读本地数据，无外网查询。
- `PATCH /nodes/{id}/map-location`：管理员；`latitude/longitude/label`，两坐标同时设置或同时null。
- 不增加数据库表或迁移。快照有字段数、数值范围和总大小限制；旧agent无快照时正确显示未知。
- 采集独立后台任务每60秒，NAT成功缓存15分钟、失败60秒再试，不阻塞5秒指标采集。物理默认出口辨认、curl强制接口绑定、禁代理环境及curlrc，校验实际源地址；无法证明出口则未知。当前自动NAT绑定实现为Linux；其他平台可人工定位，WG工具可用时仍可采集。
- 支持旧版wg-tools endpoints续行省略接口前缀的格式，仍严格白名单解析，不把缺项当空peer。
