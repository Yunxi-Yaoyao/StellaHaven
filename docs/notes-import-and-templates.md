# 笔记目录、导入与模板

## 使用方式

- 有直属子页面的笔记自动显示为目录页；目录独立于 Markdown 正文。标题下列出直属子页面，按行展开后代。没有子页面时为普通文章，仍可继续下挂。
- 手机有正文时默认折叠目录，空正文默认展开；手动选择按账号、工作区和页面记忆。反向引用默认收起。
- 列表中的“导入 .md / .txt / .zip”支持文件选择和拖拽。拖到列表某一页面时预选为父页面，拖到空白区或正文时预选工作区根目录；导入弹窗仍可调整目标。
- 先选择工作区和树形目标。Markdown/TXT 是逐文件新建，ZIP 先预览结构，再逐包点击“导入此 ZIP”。混合选择时两种批次分别显示与确认，不覆盖当前编辑器。
- ZIP 里的文件夹变为目录页面，文件夹中的 README.md 作为该目录正文，不另建重复 README 子页。根 README.md 作为根级文章。Markdown/Markdown 扩展名和 TXT 作为文章，其余文件作为附件。
- 相对链接按 ZIP 源路径映射，导入后使用文档 ID 导航；不同目录的同名文章不依赖标题匹配。图片及附件改为受登录权限保护的附件地址。找不到的相对目标保留原文并显示警告。
- 同级同名新建时自动加序号，不覆盖已有页面。导入首次提交后目标和编码锁定；失败重试复用导入标识。单包数据库变更统一提交，失败回滚并清理仅本次新写的附件文件。
- 直接拖一个本地文件夹尚不递归导入，请先压成 ZIP。只有图片或 PDF 的正文拖放继续走原附件上传功能。

## 模板

“新建笔记”和“新建子页面”共用模板选择弹窗：

1. 空白文章。
2. 文章模板：摘要、核心结论、概念、操作、验证、关联、参考、待办。
3. 事件记录模板：影响、时间线、根因、处理、验证、回滚与后续行动。
4. 我的模板：将任意笔记在工具栏“设为模板”，或添加“模板”标签，即可作为本工作区模板跨设备复用。编辑该笔记即更新模板；“移出模板库”只移除标记，不删除原文。

创建时复制预览中的正文到新页面，不修改模板原文，不复制子页面。自定义模板中的链接保留原资源引用，不复制附件文件；原资源删除后引用可能失效。模板状态复用现有标签与文档结构，不引入第二套正文存储或新表。

## 限制与兼容

- 独立 MD/TXT：每批 50 个文件、单个 5 MiB、总计 20 MiB。
- ZIP：压缩包 32 MiB、展开总量 128 MiB、单文件 25 MiB、最多 2000 项（含隐式目录）、32 层路径、路径 UTF-8 1024 字节、单组件 255 字节、最大压缩比 200。
- 正文支持 UTF-8、UTF-16 BOM、GB18030。ZIP 文件名遵循 ZIP 格式自身编码标记；正文编码切换不重解释文件名。
- 拒绝绝对路径、穿越、符号链接、加密、不支持的压缩格式、重复规范路径、目录文件冲突和超限包。
- 链接扫描保护围栏、缩进和行内代码，支持常规行内／引用式 Markdown 以及 wiki 路径、空格、平衡括号；不是完整 CommonMark AST，特殊嵌套容器语法需核对预览警告与导入结果。
- 不需要数据库结构迁移。ZIP 幂等回执保存于现有 AppConfig；正文仍为单一 Markdown。

## 验证

- `npm run test:notes`：富文本、导入、目录、模板、ID 导航以及页面回归。
- `npm run build`：vue-tsc 与生产构建。
- `UV_PYTHON=3.13 uv run pytest tests/ tests_isolated/ -q`：后端全量测试。
- 构建后 `STELLA_LIVE_BROWSER=1 UV_PYTHON=3.13 uv run pytest tests/test_notes_zip_browser.py -q -s`：实际 Chromium → 本地 HTTP → FastAPI → 独立测试 PostgreSQL。临时账号真实登录，临时附件目录；断言生产库不可用作测试目标。该可选项在无本地 Chromium 的 CI 中跳过。

2026-09-09 发布前结果：全页面回归 35 passed；后端 281 passed、30 subtests passed，1 个可选浏览器测试常规跳过。该浏览器测试单独启用实测通过：7 页面、1 附件、精确 ID 导航、图片载入、自定义模板复用、原文保持不变。截图用于辅助检查，手机真机视觉由使用者终审。
